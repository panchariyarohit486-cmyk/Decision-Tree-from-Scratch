# Decision Tree from Scratch

This repository contains a **Decision Tree Classifier implemented from scratch in Python**, without using `sklearn`’s `DecisionTreeClassifier`.  
The project focuses on understanding how decision trees work internally by building the complete algorithm step by step.

---

##  Project Overview

A Decision Tree is a supervised machine learning algorithm used for classification and regression.  
It works by recursively splitting the dataset based on feature values to maximize information gain, forming a tree-like structure of decisions.

In this project, the entire logic — from calculating split criteria to making predictions — is implemented manually to provide a clear understanding of the core concepts.

---

##  Repository Structure

- `scratch_implementation.ipynb`  
  Jupyter Notebook containing the full implementation of the Decision Tree algorithm from scratch, including data processing, tree construction, and prediction.

---

##  Features

- Decision Tree implemented **from scratch**
- No use of high-level ML models
- Recursive tree building logic
- Information Gain / Entropy based splitting
- Classification prediction support
- Beginner-friendly, step-by-step implementation
